# Stone, Paper, Scissors Game 🪨📜✂️

A classic CLI-based Stone, Paper, Scissors game developed in C++, featuring customizable round counts, randomized computer AI, dynamic console color feedback based on round outcomes, and comprehensive final game statistics.

## 🌟 Features / الميزات

* Customizable Rounds: Choose to play anywhere from 1 to 10 rounds per game session.
* Randomized AI: Play against an automated computer opponent with random choice generation.
* Dynamic Color Feedback: Screen colors automatically shift based on performance (Green for Player win, Red for Computer win, Yellow for Draw).
* Detailed Game Summary: Displays complete post-game analytics including Player Wins, Computer Wins, Draws, and Final Winner determination.
* Replay Functionality: Seamlessly restart new game sessions without restarting the application.

## 🚀 How to run the project / طريقة تشغيل المشروع

### English:
1. Clone this repository or download the source code.
2. Open the solution file (.sln or .slnx) using Visual Studio.
3. Press F5 to build and run the application.

### العربية:
1. قم بتحميل أو عمل Clone للمستودع على جهازك.
2. افتح ملف الـ Solution (.sln أو .slnx) باستخدام برنامج Visual Studio.
3. اضغط على زر F5 لتشغيل التطبيق وبدء اللعب.
